# Jogo de Xadrez Interativo

Jogo de xadrez desenvolvido como desafio durante minha formação técnica em **Desenvolvimento Web e Cibersegurança**.

O projeto foi criado para atender ao desafio de desenvolver um jogo interativo que pudesse ser utilizado por toque em um **quadro inteligente**.

## Sobre o projeto

A ideia do projeto surgiu como uma proposta de criar um jogo de xadrez que pudesse ser jogado diretamente pela tela do quadro inteligente.

A aplicação possui uma interface interativa e foi desenvolvida para permitir a movimentação das peças e o acompanhamento da partida diretamente pelo navegador.

A implementação do código contou com o uso de **Inteligência Artificial como ferramenta de apoio ao desenvolvimento**. O projeto também foi utilizado como oportunidade para explorar funcionalidades de JavaScript e desenvolvimento de interfaces interativas.

## Funcionalidades

- Tabuleiro de xadrez interativo
- Movimentação das peças
- Controle de turnos
- Histórico de movimentos
- Desfazer movimentos
- Reiniciar partida
- Destaque de casas disponíveis
- Interação por toque
- Interface adaptada para utilização em quadro inteligente

## Tecnologias

- HTML
- CSS
- JavaScript

## Conceitos estudados

- Manipulação do DOM
- Eventos de interação
- JavaScript
- Desenvolvimento de interfaces interativas
- Lógica de programação
- Manipulação de elementos HTML
- Interação por toque
- Desenvolvimento de jogos para navegador

## Contexto

Projeto desenvolvido como um desafio prático durante a formação técnica.

O objetivo da atividade era criar um jogo interativo que pudesse ser utilizado em um quadro inteligente por meio de toque.

A ideia do jogo de xadrez foi proposta por mim durante o desafio, enquanto a implementação contou com auxílio de Inteligência Artificial.

## Aprendizados

O projeto proporcionou contato com conceitos de desenvolvimento de interfaces interativas, manipulação do DOM, eventos e lógica de programação em JavaScript.

Também serviu como experiência para compreender como a Inteligência Artificial pode ser utilizada como ferramenta de apoio durante o desenvolvimento.
