# ♟️ Jogo de Xadrez

Projeto de um jogo de xadrez desenvolvido com **HTML, CSS e JavaScript puro**, focado em praticar lógica de programação e manipulação do DOM.

O jogo permite movimentar as peças seguindo as regras oficiais do xadrez, incluindo validação de jogadas, troca de turnos entre jogadores e situações como xeque e xeque-mate.

Também conta com funcionalidades extras como:

* Histórico de movimentos
* Desfazer jogadas
* Reiniciar partida
* Destaque de movimentos possíveis

## 🚀 Como executar

Basta abrir o arquivo `index.html` em qualquer navegador.

## 🎯 Objetivo

Este projeto foi criado com o objetivo de aprimorar habilidades em JavaScript e entender melhor a implementação de regras mais complexas dentro de uma aplicação web.
